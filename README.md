# Gaber's Store

A small static landing page for a football boots shop, built with plain HTML and CSS. It has a section and a "Trending Boots" section with three product cards.

## Demo

Live demo: [https://moatazmuhamed91.github.io/p2/]

Or open index.html in any browser. No build step, no server, no dependencies.

## Features

- section with the store name, a tagline and a boot image
- Navigation bar (Home, Men, Player's Edition, Kids). "Player's Edition" scrolls to the trending section. The other links are placeholders.
- "Trending Boots" section with three cards: Lionel Messi, Muhamed Salah and Lamine Yamal, each with a rank, a demo price and sizes
- Fixed red circle background
- Responsive layout with media queries at 1200px and 1000px

## Tech

- HTML
- CSS
- No JavaScript
